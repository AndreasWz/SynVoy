Privacy

For the operator of this site: the sections below describe what the SynVoy software stores. Before the site is opened to the public, add who is responsible, the legal basis, how long the web server in front keeps its access logs, and the rights of visitors as your law requires, and then remove this notice.

In short

There are no accounts, no cookies and no tracking. The pages load nothing from other websites: fonts and scripts come from this site.

What is stored when you start a search

  • The search itself: the accession or the protein sequence you entered, the name you gave it, the genomes you chose, and the time. They are needed to run the search and to show the result.
  • The result and the logs of the search. They are deleted, together with the sequence, when the result expires: a set number of days after the search, or after it was last asked for again. What stays is the name of the search and the list of genomes, so that an old link can still say what it once showed.
  • Your address on the internet is not stored as it is. A code made from it with a key kept on this server is used to keep to the limits per visitor. The code is removed from your search when the search has ended; the note that you started a search, used for the limit per day, is deleted after two days.
  • Your e-mail address, only if you enter one. It is used for the single message that tells you the search has ended and is deleted right after.

Who can see a search

Every search has a link with a long random part. Whoever has the link can see the search and its result; there is no other way to reach it, and the links are not listed anywhere. If you paste a sequence that is not public, treat the link like the sequence.

If someone else starts exactly the same search (the same sequence, the same genomes), they get the same result page. They had the sequence already.

What is kept in your browser

The list "Your searches on this device" is kept in your browser's storage, with the links and a key that lets this browser cancel its own searches. It never leaves your browser. Clearing the browser's data removes it.

What leaves this server

When you enter an accession, the server asks UniProt or NCBI for that protein. They see the accession and the address of this server, not yours. Sequences you paste are not sent anywhere.

When you name a species or a genome that is not on this server, the server asks NCBI for it and downloads the genome from there. NCBI sees the species name or the genome's accession and the address of this server, not yours. A genome fetched this way stays on the server and is listed for other visitors; who asked for it is not recorded.
